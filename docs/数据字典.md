# `governed.db` 数据字典（v2 · 双账号）

> 由 `build_governed_db.py` 从解密后的微信库生成。
> 设计依据见 `数据库治理方案.md`；**下游迁移见 `下游迁移指南.md`**。

**账号维度**

| `account` | 含义 | 号主 wxid（仅配置，不进库） |
|-----------|------|---------------------------|
| `personal` | 个人号 | `wxid_personal_owner`（仅 `accounts.local.py` 配置） |
| `work` | 工作号 | `wxid_work_owner`（仅 `accounts.local.py` 配置） |

**预期规模（v2 全量构建后，2026-06 实测）**

| 表 | 合计（约） | 说明 |
|----|------------|------|
| `contacts` | ~28k | |
| `chatrooms` | ~700 | |
| `chatroom_members` | ~40k | |
| `messages` | **~238 万** | personal ~236 万 + work ~1.9 万；源库扫描 ~310 万行，跨分片去重跳过 ~73 万 |
| `build_meta` | ~1.4k | 每个 `Msg_*` 源表一行水位 |

> **下游 agent 只需查前 4 张业务表**；`build_meta` 供构建脚本增量使用，可忽略。

---

## 1. `contacts` — 联系人主表

每个 **account**、每个联系人一行，主键 **`(account, username)`**。

| 字段 | 类型 | 可空 | 来源 | 含义 |
|------|------|------|------|------|
| `account` | TEXT | PK | 配置 | 短标签：`personal` / `work` |
| `username` | TEXT | PK | contact.username | 业务标识（`wxid_*` / `*@chatroom` / `*@im.chatroom` / `gh_*` / `*@openim`） |
| `type` | TEXT | 否 | username 后缀推导 | `person` / `chatroom` / `official` / `openim` |
| `is_friend` | INTEGER | 否 | local_type | `1`=好友；`0`=仅群成员等非好友 |
| `alias` | TEXT | 是 | contact.alias | 微信号 |
| `nick_name` | TEXT | 是 | contact.nick_name | 昵称 |
| `remark` | TEXT | 是 | contact.remark | 备注名 |
| `description` | TEXT | 是 | contact.description | 好友描述 |
| `signature` | TEXT | 是 | extra_buffer #4 | 个性签名 |
| `gender` | INTEGER | 否 | extra_buffer #2 | `0`未知 / `1`男 / `2`女 |
| `country` | TEXT | 是 | extra_buffer #5 | 国家/地区 |
| `province` | TEXT | 是 | extra_buffer #6 | 省份 |
| `city` | TEXT | 是 | extra_buffer #7 | 城市 |
| `labels` | TEXT(JSON) | 是 | extra_buffer #30 | 标签名数组，如 `["标签A","标签B"]` |
| `head_img_url` | TEXT | 是 | contact.big_head_url | 头像 URL |

**`type` 推导**：`@chatroom` 或 `@im.chatroom` → `chatroom`；`@openim` → `openim`；`gh_*` → `official`；其余 → `person`。

---

## 2. `chatrooms` — 群聊信息

主键 **`(account, username)`**。

| 字段 | 类型 | 可空 | 来源 | 含义 |
|------|------|------|------|------|
| `account` | TEXT | PK | 配置 | `personal` / `work` |
| `username` | TEXT | PK | chat_room.username | 群 ID |
| `group_owner` | TEXT | 是 | chat_room.owner | **群主** wxid（勿与 `account` 混淆） |
| `announcement` | TEXT | 是 | chat_room_info_detail | 群公告 |
| `announcement_time` | INTEGER | 是 | chat_room_info_detail | 公告时间（Unix 秒） |

> v1 字段 `owner_username`（群主）在 v2 改名为 **`group_owner`**。

---

## 3. `chatroom_members` — 群成员

主键 **`(account, room_username, member_username)`**。

| 字段 | 类型 | 可空 | 含义 |
|------|------|------|------|
| `account` | TEXT | PK | `personal` / `work` |
| `room_username` | TEXT | PK | 群 ID |
| `member_username` | TEXT | PK | 成员 wxid |

---

## 4. `messages` — 聊天记录

| 字段 | 类型 | 可空 | 含义 |
|------|------|------|------|
| `id` | INTEGER | PK | 自增全局 id |
| `account` | TEXT | 否 | `personal` / `work` |
| `chat_username` | TEXT | 否 | 会话对象（在该 account 内） |
| `local_id` | INTEGER | 是 | 该会话源表内本地 id；与 `account`+`chat_username` 组成增量去重键 |
| `server_id` | INTEGER | 是 | 服务器消息 id；**在 account 内唯一**；`0`=本地消息 |
| `timestamp` | INTEGER | 否 | Unix 秒 |
| `sender_username` | TEXT | 是 | 发送者；**该 account 下自己为 `me`** |
| `is_self` | INTEGER | 否 | `1`=自己发 |
| `type` | TEXT | 否 | `text`/`quote`/`image`/…（见 §4.1） |
| `content` | TEXT | 是 | 可读正文 |
| `media_ref` | TEXT(JSON) | 是 | 媒体外链 |
| `reply_to` | INTEGER | 是 | 被引用消息的 `server_id`（**同 account 内**自关联） |
| `reply_quote` | TEXT(JSON) | 是 | 原文不在库时的引用快照 |

**索引/约束**

- `UNIQUE(account, server_id) WHERE server_id != 0`
- `UNIQUE(account, chat_username, local_id)` — 含 `server_id=0` 本地消息；增量去重
- `INDEX(account, chat_username)`、`INDEX(reply_to)`

---

## 5. `build_meta` — 增量水位（构建内部）

| 字段 | 类型 | 含义 |
|------|------|------|
| `account` | TEXT PK | `personal` / `work` |
| `msg_table` | TEXT PK | 源库表名，如 `Msg_a1b2c3...`（含 `Msg_` 前缀） |
| `max_local_id` | INTEGER | 该表已处理的最大 `local_id` |
| `max_timestamp` | INTEGER | 可选，该表已见的最大 `create_time` |
| `updated_at` | INTEGER | 水位更新时间（Unix 秒） |

全量构建时写入；`--incremental` 时只读 `local_id > max_local_id` 的新行。

---

## 6. 关系图

```
contacts(account, username) ──< chatroom_members(account, member_username)
chatrooms(account, username) ──< chatroom_members(account, room_username)
contacts(account, username) ──< messages(account, chat_username)
contacts(account, username) ──< messages(account, sender_username)  -- 自己=me
messages(account, reply_to) ──> messages(account, server_id)
messages(account, server_id) ──> <account 对应>/media_0.db / message_resource.db
build_meta(account, msg_table)  -- 增量水位，下游可忽略
```

### 4.1 消息类型

见 `数据库治理方案.md` §3.4 按类型表。

### 4.2 媒体回查

先取 `messages.account` → 对应 `wechat-decrypt-{personal|work}/decrypted/message/`，再查 `media_0.db` / `message_resource.db`。

### 4.3 引用查原文

```sql
SELECT q.content, COALESCE(o.content, q.reply_quote) AS quoted
FROM messages q
LEFT JOIN messages o
  ON o.account = q.account AND o.server_id = q.reply_to AND o.server_id != 0
WHERE q.account = 'personal' AND q.type = 'quote';
```
